# homebrew-reclaim

Homebrew tap for [reclaim](https://github.com/ihdev524/reclaim) — a deliberately
boring macOS disk cleaner, app uninstaller, and app updater.

```sh
brew tap ihdev524/reclaim
brew install reclaim
```

The formula in `Formula/` is generated automatically by GoReleaser on each
tagged release of the main repository. Don't edit it by hand.
